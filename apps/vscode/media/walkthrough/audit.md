## How healthy is this project?

The health check looks for:

- **Secrets**: API keys, private keys, database passwords, `.env` files in git
- **Packages**: known vulnerabilities, with the version to update to
- **Risky code**: SQL and command injection, unsafe HTML, open CORS, JWT mistakes, weak hashing
- **Code health**: huge files, unused files, missing tests

You get a score out of 100, shown as the light on Byte's chest. It runs weekly on its own after this.

Everything runs on your machine.
